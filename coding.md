# Coding Assistants

- [Continue](https://github.com/continuedev/continue) — open-source AI coding assistant. Model/API may cost money.
- [Aider](https://github.com/Aider-AI/aider) — terminal-based AI pair programmer. Model/API may cost money.
- [Windsurf](https://windsurf.com/) — AI-assisted coding environment. Free tier may have limits.
- [Ollama](https://ollama.com/) — run supported models locally.
