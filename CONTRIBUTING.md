# Contributing

Thanks for helping improve Free AI Tools!

## Before submitting
- Make sure the tool has an official website or official source-code repository.
- Confirm that it offers a free plan, free credits, or is open source.
- Be precise: do not describe a limited free tier as unlimited.
- Check that the link works and is not a referral link.
- Avoid duplicate entries.

## Entry format
Use this format in the relevant category file:

| [Tool name](https://official-url.example/) | One-sentence description | Free plan / Open source / Free credits; mention limits |

## Pull requests
Keep changes focused, explain what changed, and include a source link for pricing claims where possible.
