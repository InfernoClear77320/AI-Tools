## 🏷️ Free access labels

We use these labels to make pricing clearer:

- **Free plan:** A hosted service with a no-cost tier and possible usage limits.
- **Open source:** Source code is available under a license; hosting, hardware, or model/API usage may still cost money.
- **Free credits:** A limited amount of usage is provided at no cost.
- **Freemium:** Core features are free, while advanced features require payment.

## 🤝 How to contribute

Found a useful tool or spotted outdated information?

1. Read [CONTRIBUTING.md](CONTRIBUTING.md).
2. Add the tool to the most relevant category file in `tools/`.
3. Include the official website, a concise description, and an honest free-access label.
4. Open a pull request.

Please do not submit referral links, misleading “free trial” claims, or tools without a working official page.
